# React Libraries Summary

This document provides a summary of all React libraries used in the project and their purposes.

## Libraries

### 1. React

- **Library:** `react`
- **Purpose:** Core library for building user interfaces.

### 2. Next.js

- **Library:** `next`
- **Purpose:** Framework for server-rendered React applications.

### 3. Tailwind CSS

- **Library:** `tailwindcss`
- **Purpose:** Utility-first CSS framework for styling.

### 4. Next-i18next

- **Library:** `next-i18next`
- **Purpose:** Internationalization framework for Next.js applications.

### 5. React Chart.js 2

- **Library:** `react-chartjs-2`
- **Purpose:** React wrapper for Chart.js, used for creating charts.

### 6. Chart.js

- **Library:** `chart.js`
- **Purpose:** JavaScript library for creating charts.

### 7. Next Image

- **Library:** `next/image`
- **Purpose:** Optimized image component for Next.js.

### 8. React Router

- **Library:** `next/router`
- **Purpose:** Routing library for Next.js applications.

### 9. JWT Decode

- **Library:** `jwt-decode`
- **Purpose:** Library for decoding JSON Web Tokens (JWT).

### 10. Date-fns

- **Library:** `date-fns`
- **Purpose:** Utility library for date manipulation.

## Usage

These libraries are used throughout the project to build and manage the user interface, handle routing, manage state, perform internationalization, create charts, and handle authentication.
